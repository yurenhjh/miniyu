## 三、一键复现（打包内最高效验收路径）

```bash
# 1) 环境
pip install -r requirements.txt

# 2) 跑测试（552 全绿）
python -m pytest -q

# 3) 无 key 也能跑（离线确定性脑，演示全流程）
python examples/agent_cli.py          # 或网页版 python examples/miniyu_web.py

# 4) 填自己的 key 走真实 LLM
cp config.yaml.example config.yaml   # 填 llm.api_key / llm.model
python examples/miniyu_web.py

# 5) Linux 桌面自动化（验收目标环境）
bash setup_linux.sh                  # 装工具/依赖/生成配置；选 Xorg 会话
bash run_miniyu_web.sh
```
